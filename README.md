# SyncSpace

A whiteboard-first collaboration space with guest access, real-time drawing, and integrated video meetings.

Implementation milestones:

1. Guest rooms, signed access tokens, real-time collaboration, and snapshot persistence.
2. React workspace, drawing tools, live cursors, chat, and LiveKit meeting UI.
3. Concurrency and recovery verification, PostgreSQL/Docker deployment, and documentation.

Local setup and deployment instructions will be added with the corresponding milestones.
